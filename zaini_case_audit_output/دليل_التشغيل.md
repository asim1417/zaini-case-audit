# دليل التشغيل

نظام فحص المستندات القانونية — خطوات التشغيل من الصفر.

## المتطلبات
- نظام: Linux/Mac/Windows مع Python 3.9+.
- أدوات نظام (للـOCR وفكّ الضغط):
  `tesseract-ocr` و`tesseract-ocr-ara` و`poppler-utils` و`unrar` و`p7zip-full`.
- مكتبات بايثون: `pip install -r requirements.txt`.

> أسهل طريقة: استخدم Docker (يثبّت كل شيء بأمر واحد) — انظر القسم «التشغيل عبر Docker».

## التشغيل عبر Docker (موصى به)
```
docker build -t legal-audit .
docker run --rm -v "$PWD:/app" legal-audit \
  python3 scripts/legal_audit.py run قضيتي
```

## التشغيل اليدوي (بايثون)
### 1) إنشاء قضية
```
python3 scripts/legal_audit.py new قضيتي
```
ينشئ مجلد `cases/قضيتي/` فيه `staging/` و`case_config.json`.

### 2) وضع المستندات (اختر ما يناسبك)
- **الأسهل:** ضع الملفات الحقيقية (PDF/Word/Excel/صور) في `cases/قضيتي/staging/docs/`
  — يفهرسها النظام تلقائياً بعناوينها ويستخرج نصّها.
- أو ضع النصوص الجاهزة في `staging/text/<معرّف>.txt`.
- الأرشيفات (zip/rar) والصور: ضعها في `staging/raw/` لتُفكّ ويُجرى OCR لها تلقائياً.
- (اختياري) دراسة/فهرس بروابط: `staging/study/source_study.docx`.

### 3) تعبئة الإعداد (يقوّي الدقة)
عدّل `cases/قضيتي/case_config.json`: رقم القضية، الأطراف، أرقام الصكوك، اسم الشركة.
(يمكن تركه شبه فارغ — النظام يكتشف أسماء الأطراف من النص تلقائياً أيضاً.)

### 4) التشغيل
```
python3 scripts/legal_audit.py run قضيتي
```
يشغّل تلقائياً بالترتيب: فهرسة ← فكّ ضغط/OCR ← تصحيح القراءة ← اكتشاف الأطراف ←
استخراج وتصنيف ← تحليل ← تقارير Word/Excel ← فحص الجودة ← حزمة المخرجات.

### 5) النتائج
داخل `cases/قضيتي/`:
- `outputs/excel/00_master_documents.xlsx` — الفهرس الرئيسي (ابدأ هنا).
- `outputs/word/00_ملخص_القضية.docx` — الموجز التنفيذي.
- `outputs/word/documents/` — ملف Word لكل مستند (بأقسام معنونة).
- `outputs/csv/` — جداول (كيانات، أسباب نقض، صكوك، محطات، مبالغ، فحص الجودة...).
- `outputs/json/full_audit_data.json` — كل البيانات المهيكلة.
- `case_outputs_bundle.zip` — حزمة كل المخرجات.

## إضافة ملفات جديدة لقضية قائمة (إلحاق)
وصلتك مستندات جديدة لقضية موجودة؟ لا تبدأ من جديد:
1. ضع الملفات الجديدة فقط في `cases/<القضية>/staging/docs/` (أو الأرشيفات/الصور في `staging/raw/`).
2. أعد التشغيل: `python3 scripts/legal_audit.py run <القضية>`.
المحرّك **يفهرس الجديد فقط ويُلحقه** بالفهرس الموجود (لا يكرّر ولا يفقد القديم)،
ثم يعيد توليد كل التقارير محدَّثة.

## أوامر مساعدة
```
python3 scripts/legal_audit.py list           # عرض القضايا
python3 scripts/legal_audit.py new <اسم>      # قضية جديدة
python3 scripts/legal_audit.py run <اسم>      # تشغيل كامل
```

## استكشاف الأخطاء
- نصّ ضعيف لملف ممسوح؟ ضع نسخته PDF في `staging/raw/` وأعد `run` (OCR 300DPI).
- ملف بلا عنوان؟ سمِّه باسم واضح في `staging/docs/`.
- راجع `outputs/csv/14_readability_qc.csv` لمعرفة الملفات التي تحتاج انتباهاً.

> تذكير: كل المخرجات مساعدة آلية تحتاج مراجعة المحامي، والمعالجة محلية بالكامل.
