# نظام الفحص القانوني الآلي — دليل المنتج

أداة برمجية لفحص مستندات القضايا القانونية آلياً: جرد، استخراج كيانات، تصحيح وقراءة
النصوص العربية الممسوحة (OCR)، تصنيف، خط زمني، تقارير Word/Excel، وفحص جودة — تعمل
**محلياً بالكامل** للحفاظ على سرية القضايا.

> تنبيه: كل المخرجات «مساعدة آلية تحتاج مراجعة المحامي»، وليست رأياً قانونياً نهائياً.

## أداة متعدّدة القضايا (واجهة موحّدة)
المحرّك مشترك (مجلد `scripts/`)، وكل قضية مجلد مستقل تحت `cases/<اسم>/`.

```
# إنشاء قضية جديدة
python3 scripts/legal_audit.py new <اسم_القضية>

# تشغيل الفحص الكامل على قضية
python3 scripts/legal_audit.py run <اسم_القضية>

# عرض القضايا الموجودة
python3 scripts/legal_audit.py list
```

### خطوات قضية جديدة (٤ خطوات)
1. `new <اسم>` لإنشاء الهيكل.
2. ضع نصوص المستندات في `cases/<اسم>/staging/text/<id>.txt` وبياناتها في `staging/parts/*.jsonl`
   (أو ضع نسخ الملفات في مجلد محلي واستخدم وضع `--root`).
3. عدّل `cases/<اسم>/case_config.json` (رقم القضية، الأطراف، الصكوك، الشركة).
4. `run <اسم>` — تحصل على الفهرس والتقارير وملفات Word والحزمة داخل مجلد القضية.

## التثبيت
**عبر Docker (موصى به — تثبيت بأمر واحد):**
```
docker build -t legal-audit .
docker run --rm -v "$PWD:/app" legal-audit python3 scripts/legal_audit.py run <اسم_القضية>
```
**أو يدوياً:**
```
pip install -r requirements.txt
# + أدوات نظام: tesseract-ocr tesseract-ocr-ara poppler-utils unrar p7zip-full
```

## المكوّنات (مجلد scripts)
| السكربت | الوظيفة |
|---|---|
| legal_audit.py | الواجهة الموحّدة (new/run/list) |
| improve_readability.py | تصحيح اتجاه النص العربي الممسوح |
| build_study_index.py | فهرس من دراسة بروابط (اختياري) |
| audit_case.py | الفحص: استخراج وتصنيف (يقرأ CASE_ROOT و case_config.json) |
| analyze_case.py | خط زمني + أسباب نقض + مبالغ + إحالات |
| case_brief.py | موجز موحّد + سجل صكوك + محطات |
| process_binaries.py | فكّ ضغط zip/rar/7z + OCR |
| make_word.py / make_master_excel.py | مخرجات Word و Excel |
| qc_readability.py | فحص جودة القراءة |
| make_bundle.py | حزمة المخرجات (UTF-8) |
| run_all.sh | تشغيل كامل لقضية واحدة (المجلد الافتراضي) |

## الخصوصية والامتثال
- معالجة محلية بالكامل؛ لا تخرج بيانات القضية لأي خدمة خارجية.
- يُنصح بتشفير القرص وضبط صلاحيات الوصول لملفات القضايا.
- التحقق من النصوص النظامية من مصادرها الرسمية قبل الاعتماد.
