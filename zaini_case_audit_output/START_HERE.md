# ابدأ هنا — عدّة فحص المستندات القانونية

هذه عدّة أداة (كود فقط، بلا بيانات أي قضية) لفحص مستندات القضايا آلياً وإنتاج فهرس
وتقارير وملفات Word وExcel قابلة للقراءة.

> كل المخرجات «مساعدة آلية تحتاج مراجعة المحامي» وليست رأياً قانونياً نهائياً.
> المعالجة محلية بالكامل (بيانات القضية لا تخرج من جهازك).

## ثلاث طرق للتشغيل

### 1) عبر وكيل ذكاء برمجي (الأسهل لغير التقنيين)
ارفع هذه العدّة لوكيل يستطيع تنفيذ الأوامر (مثل Claude Code)، والصق له محتوى
`AGENT_PROMPT.md`. سيتولّى التثبيت والتشغيل على قضيتك.

> ملاحظة: شات كلود العادي (claude.ai) لا «يشغّل» الكود؛ يصلح فقط لتحليل المخرجات
> بعد توليدها. التشغيل يحتاج وكيلاً برمجياً أو جهازاً عليه بايثون.

### 2) عبر Docker (تثبيت بأمر واحد)
```
docker build -t legal-audit .
docker run --rm -v "$PWD:/app" legal-audit \
  python3 scripts/legal_audit.py run قضيتي
```

### 3) يدوياً (بايثون على جهازك)
```
pip install -r requirements.txt
# + أدوات نظام: tesseract-ocr tesseract-ocr-ara poppler-utils unrar p7zip-full
python3 scripts/legal_audit.py new قضيتي
# جهّز المستندات والإعداد (انظر NEW_CASE_GUIDE.md)
python3 scripts/legal_audit.py run قضيتي
```

## الملفات المرجعية
- `PRODUCT_README.md` — دليل المنتج الكامل والأوامر.
- `NEW_CASE_GUIDE.md` — كيفية تجهيز قضية جديدة خطوة بخطوة.
- `AGENT_PROMPT.md` — نص جاهز للصقه لوكيل الذكاء.
- `PRODUCT_ROADMAP.md` — خارطة تطوير المنتج.
