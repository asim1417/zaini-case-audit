# فهرس الحزمة المتكاملة — نظام الفحص القانوني الآلي

هذه حزمة متكاملة تضم الكود وكل ملحقاته وأدلة التشغيل وفكرة المشروع.
(كود وأدلة فقط — بلا بيانات أي قضية، حفاظاً على السرية.)

## ابدأ من هنا
1. اقرأ: `فكرة_الكود_وهدفه` (ما هو النظام ولماذا).
2. ثم: `دليل_التشغيل` (كيف تشغّله خطوة بخطوة).
3. للتشغيل عبر وكيل ذكاء: الصق محتوى `AGENT_PROMPT.md`.

## محتويات الحزمة
- `scripts/` — الكود الكامل (محرّك الفحص + الواجهة الموحّدة legal_audit.py).
- `requirements.txt` + `Dockerfile` — التثبيت (يدوي أو بأمر واحد عبر Docker).
- `case_config.template.json` — قالب إعداد القضية.
- `cases/` — مكان قضاياك (فارغ).

### الوثائق
- `فكرة_الكود_وهدفه.md/.docx` — فكرة المشروع وهدفه.
- `دليل_التشغيل.md/.docx` — دليل التشغيل الكامل.
- `START_HERE.md` — بداية سريعة (٣ طرق تشغيل).
- `NEW_CASE_GUIDE.md` — تجهيز قضية جديدة بالتفصيل.
- `AGENT_PROMPT.md` — نص جاهز لوكيل الذكاء الاصطناعي.
- `PRODUCT_README.md` — دليل المنتج والأوامر.
- `PRODUCT_ROADMAP.md` — خارطة تطوير المنتج.
- `دليل_استخدام_كلود.md/.docx` — استخدام النتائج داخل محادثة كلود.

## ملف الكود الرئيسي
- `scripts/legal_audit.py` — الواجهة: `new` / `run` / `list`.
- `scripts/run_all.sh` — تشغيل كامل لقضية واحدة.

## تنبيه
كل المخرجات مساعدة آلية تحتاج مراجعة المحامي. المعالجة محلية بالكامل.
